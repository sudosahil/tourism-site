# Tourism Website - WPL Experiment 2

This is a multi-page tourism website built with HTML5 and CSS3.

## Files Included

1. **index.html** - Home Page
2. **login.html** - Login Page
3. **register.html** - Registration Page
4. **packages.html** - Tour Packages Catalogue
5. **timetable.html** - Class Timetable
6. **style.css** - External CSS Stylesheet

## Features

- Multi-page website structure
- Responsive navigation menu
- Styled forms with card layout
- Data tables for packages and timetable
- Consistent styling across all pages
- External CSS for separation of content and presentation

## CSS Concepts Covered

- Basic page styling (background, font, margin, padding)
- Header and footer styling
- Horizontal navigation bar
- Card styling (border, shadow, center)
- List styling
- Consistent layout and reusable CSS

## How to Use

1. Extract all files to a folder
2. Open index.html in your web browser
3. Navigate between pages using the menu links
4. All styling is applied from style.css

## To Upload to GitHub

1. Create a new repository on GitHub
2. Add all files to the repository
3. Commit and push to GitHub
4. Enable GitHub Pages in repository settings
5. Your website will be live at: https://yourusername.github.io/repository-name/

## Questions Answered

This website demonstrates the solutions to:
- CSS responsive layouts using Flexbox
- Media queries for responsive design
- CSS animations and transitions
- Navigation menu styling
- Form and card styling
- Table styling
- Consistent layout maintenance across multiple pages
