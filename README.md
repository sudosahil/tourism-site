# TRAVEL PARADISE - TOURISM WEBSITE

## Experiment 3: Bootstrap Framework Implementation

A responsive, component-rich tourism portal built using Bootstrap 5 framework.

---

## Features Implemented

### Task 1: Layout & Container Setup
- Responsive containers using `.container` and `.container-fluid`
- Proper margin, padding, and alignment across all viewport sizes
- Breakpoint constraints for responsive design

### Task 2: Responsive Grid Layout
- Bootstrap grid system with rows and columns
- Responsive column classes: `.col-md-4`, `.col-sm-12`
- Flexible layouts that stack on mobile and display side-by-side on desktop
- Product cards displayed in 3-column grid on desktop, 1-column on mobile

### Task 3: Navigation & Search Bar
- Responsive navigation bar with dropdown menus
- Collapsible navbar for mobile devices
- Search input-group with search icon (Font Awesome)
- Navigation links for Home, Destinations, Packages, Login

### Task 4: Circle Image Shaping
- Images styled with `.rounded-circle` utility class
- Profile/product avatars displayed as circles
- Responsive image helpers for scaling
- Hover animation on circular images

### Task 5: Alerts & Pagination
- Interactive alert messages with dismissible buttons
- Different alert types: info, warning, success, danger
- Standard paginated navigation at bottom of pages
- `.pagination`, `.page-item`, `.page-link` classes used
- Pagination linking between pages

## Responsive Design

### Breakpoints Implemented
- **Desktop** (>= 768px): Full layout with 3-column grid
- **Tablet** (576px - 767px): 2-column grid
- **Mobile** (< 576px): 1-column stacked layout

### Features
- Collapsible mobile navigation
- Responsive images
- Flexible forms
- Scrollable tables on mobile
- Touch-friendly buttons

---

## Bootstrap Components Used

- `.navbar` - Navigation bar
- `.container` - Responsive container
- `.row` & `.col-*` - Grid system
- `.card` - Content cards
- `.btn` - Buttons
- `.form-control` - Form inputs
- `.input-group` - Input groups with icons
- `.table` - Data tables
- `.alert` - Alert messages
- `.pagination` - Pagination
- `.dropdown` - Dropdown menus
- `.rounded-circle` - Circular images
